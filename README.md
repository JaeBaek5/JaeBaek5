현재는 작물 생육 단계 분류, 토마토 생육 데이터 기반 머신러닝, 엣지 디바이스용 AI 앱, NoSQL/OpenData DBMS 실습, 반려동물 케어 플랫폼, 필기 렌더링 앱 등을 중심으로 프로젝트를 정리하고 있습니다.
